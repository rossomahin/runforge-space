# RunForge

Небольшое React-приложение для просмотра запусков проектов (runs).

## Возможности

- загрузка запусков через mock-сервис с имитацией задержки;
- отображение состояния загрузки и ошибки;
- повторная загрузка данных через `Retry`;
- поиск по имени запуска и репозиторию;
- фильтрация по статусу;
- комбинирование поиска и фильтра по статусу;
- сброс активных фильтров через кнопку `Reset`;
- открытие подробной информации о запуске;
- отображение логов, результата, ветки, времени создания и длительности;
- цветовые badge-компоненты для статусов;
- простая анимация появления контента;
- поддержка `prefers-reduced-motion`.

## Стек

- React
- TypeScript
- Vite
- Tailwind CSS

## Требования

- Node.js 18+
- npm или pnpm

## Установка

```bash
pnpm install
```

## Запуск в режиме разработки

```bash
pnpm run dev
```

После запуска приложение будет доступно по адресу, который выведет Vite в терминале.

## Проверка проекта

Проверка линтером:

```bash
pnpm run lint
```

Production-сборка:

```bash
pnpm run build
```

Предпросмотр production-сборки:

```bash
pnpm run preview
```

## Тесты

```bash
pnpm run test
```

Покрыты три сценария: фильтрация по статусу, поиск по названию, открытие деталей запуска.

## Данные

Сейчас приложение использует mock-данные из `src/data/runs.ts`.

Загрузка вынесена в `src/data/runsService.ts`, поэтому mock-сервис можно заменить
на реальный API без изменения компонентов списка и деталей.
